## 🚀 Featured Project

### [DevHire](https://devhire-sooty.vercel.app/login) — AI-Assisted Recruitment Platform

An AI-powered recruitment platform where recruiters bulk-upload resumes and an AI engine parses, screens, and ranks candidates against a job posting — cutting manual screening time significantly.

- Built end-to-end: system design, backend architecture, auth, AI integration
- JWT authentication + Role-Based Access Control (Admin/Recruiter, Organization model)
- Resume parsing via `pdf-parse`, bulk file handling via `Multer`
- AI-driven candidate ranking powered by the Claude API

**Stack:** React, Node.js, Express, MongoDB, Claude API, JWT

## 💻 Running Locally

```bash

git clone https://github.com/CodebyAdil/adil-portfolio.git
cd adil-portfolio

# Install dependencies
npm install

# Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
